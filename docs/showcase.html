Feature Showcase

Every document below is rendered by PeachPDF itself when this site is built, so the output always reflects the current release. Each card pairs the exact input — the HTML given to PdfGenerator.GeneratePdf, or for the declarative-API showcases the C# given to PdfGenerator.CreateDocument — with the PDF that came out. Open both and compare. The previews show the first page of each PDF, rendered on Linux with Liberation fonts (the same font substitution any Linux server without Microsoft fonts would use).

Want to render your own? Try PeachPDF in your browser — drop in an HTML file, an MHTML archive, or a ZIP of a site folder and get a PDF back. It runs entirely on your machine, in the page, with no server involved. Prefer the command line or plain C#? See the peachpdf CLI and the declarative API, which build PDFs without an HTML string.
