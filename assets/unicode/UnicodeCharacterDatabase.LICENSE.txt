BidiBrackets.txt, BidiMirroring.txt, DerivedBidiClass.txt, BidiCharacterTest.txt, and
VerticalOrientation.txt are unmodified files from the Unicode Character Database (UCD),
version 17.0.0, © 2025 Unicode, Inc. They are licensed under the Unicode License v3
("Unicode® License Agreement — Data Files and Software").

These files are bundled solely as source data / test fixtures: BidiBrackets.txt,
BidiMirroring.txt, and DerivedBidiClass.txt are parsed offline into the compact lookup
tables PeachPDF.Text.Bidi ships (see assets/unicode/generate_bidi_tables.py);
VerticalOrientation.txt is parsed the same way into the lookup table
PeachPDF.Text.VerticalOrientationTable ships (see
assets/unicode/generate_vertical_orientation_table.py, UAX #50); and BidiCharacterTest.txt
is the Unicode Consortium's own bidi conformance suite, used by the test suite to verify
the Unicode Bidirectional Algorithm (UAX #9) implementation against real, official test
vectors. None of these files themselves is shipped in the PeachPDF library or its NuGet
package.
