gsubtest-lookup3.otf is a synthetic OpenType GSUB conformance-test font from the
web-platform-tests project (css/css-fonts/support/fonts/gsubtest-lookup3.otf),
Copyright web-platform-tests contributors, licensed under the 3-Clause BSD
License.

Every glyph the font can substitute to spells out the literal word "PASS" or
"FAIL" as vector outlines - the font exists purely so a test can activate a
named OpenType feature and check which word rendered. It is bundled solely as
a test asset: PeachPDF's own bundled display fonts (Source Sans 3, Source Code
Pro) don't implement most of the rarer font-variant-caps keywords via any GSUB
lookup type at all, and this font is the only publicly available one found
that implements font-variant-caps' petite-caps/all-petite-caps via GSUB
Alternate Substitution (Lookup Type 3) - letting the test suite prove real
Alternate Substitution glyph selection end to end, not just the Single
Substitution (Lookup Type 1) path Source Sans 3 already covers for
small-caps/all-small-caps/titling-caps.
