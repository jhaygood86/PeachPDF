# `flex-direction: column` cross-axis (horizontal) alignment

_Landed 2026-07-23._

**`flex-direction: column` cross-axis (horizontal) alignment** (issue #133, the highest-impact Tailwind flexbox gap — `flex-col items-center`/`items-end`/`self-*`): column flex items ignored `align-items`/`align-self` and always stretched to the full container width. Root cause was *upstream sizing*, not missing positioning — `ComputeCrossOffsets`/`AssignLocations` already handle column symmetrically, but a column item's cross axis is **width**, and a blockified auto-width block fills the container during `PerformLayoutBlockified`, so every item reported `ActualBoxSizingWidth == containerWidth`, making `Center`/`FlexEnd` compute a ~0 offset and `Stretch` a no-op (row works "for free" because its cross axis is height, which block layout shrink-wraps). Fix (`CssLayoutEngineFlex.cs`): a new **Phase 4b** (`ShrinkColumnItemToContentWidth`, after flex-length resolution, before line-cross-size/cross-offset phases) re-lays out each non-`stretch`, auto-width column item at its fit-content width via the existing `CssLayoutEngine.GetFitContentWidth` (clamped by cross `min-width`/`max-width`), mirroring the column stretch re-layout branch (poke `Width`, lock main-axis `Height` to `FinalMainSize`, `PerformLayoutBlockified`, restore). The existing positioning code then centers/end-aligns correctly. **Scoped to non-stretch alignments** (`align is not (Stretch or "normal")`) — since `align-items` defaults to `"normal"` ≡ stretch, the common default (and explicit `stretch`) keeps full-width behavior unchanged, minimizing regression risk; `flex-start`/`center`/`flex-end`/`baseline`(→flex-start in column) all shrink-wrap. Replaced items (`<img>`/`<svg>`, the #131 cover case) get their intrinsic width from `GetMinMaxWidth`, so they center too. Covers CSS Flexbox 1 §7.5 (fit-content hypothetical cross size) / §8.3. See `FlexboxIntegrationTests` (center/flex-end shrink-wrap + position, `align-self` override, min/max-width clamp, replaced-item center, and stretch/default full-width regression guards). **Out of scope (unchanged):** cross-axis `auto` margins for column (`margin-left/right: auto` free-space absorption) — a separate Flexbox §8.1 gap, not part of #133.
