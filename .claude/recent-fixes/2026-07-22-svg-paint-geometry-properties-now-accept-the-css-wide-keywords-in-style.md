# SVG paint/geometry properties now accept the CSS-wide keywords in `<style>` rules

_Landed 2026-07-22._

**SVG paint/geometry properties now accept the CSS-wide keywords in `<style>` rules** (issue #230): `fill`/`stroke`/`stroke-width`/`stroke-dasharray`/`stroke-dashoffset`/`stroke-linejoin`/`stroke-miterlimit` previously had value converters (`Converters.PaintConverter`/`LengthOrPercentConverter`/`StrokeDasharrayConverter`/`StrokeLinejoinConverter`/`StrokeMiterlimitConverter`) with **no** `.OrGlobalValue()`/`.OrDefault()`, so `fill: revert`/`inherit`/`initial`/`unset` was **dropped at CSS-OM parse time** and never reached `SvgCssStyling.GetMatchedDeclarations` (so the #205 revert handling couldn't apply to the flagship paint properties). Each converter now has `.OrGlobalValue()`, and the merge resolves every CSS-wide keyword (CSS Cascade 4 §7.3): `initial` → the property's SVG initial value (a small `SvgInitialValues` map — `fill`→`black`, `stroke`→`none`, `stroke-width`→`1`, `stroke-dasharray`→`none`, `stroke-dashoffset`→`0`, `stroke-linecap`→`butt`, `stroke-linejoin`→`miter`, `stroke-miterlimit`→`4`, `fill-opacity`/`stroke-opacity`→`1`, `fill-rule`/`clip-rule`→`nonzero`); `inherit` → the literal `"inherit"` (the SVG paint consumers already map both `"inherit"` and a null to the inherited value); `unset`/`revert`/`revert-layer` → the null-present signal (every SVG paint/geometry property is inherited, so `unset` ≡ `inherit`). Because `IdentifierValueConverter` stores `CssText = <keyword>`, all five keywords reach the merge as their literal string regardless of the converter's value form, so this also incidentally fixed `initial`/`unset` on the properties that *already* accepted globals (`fill-opacity`/`stroke-opacity`/`fill-rule`/`clip-rule`/`stroke-linecap`), which previously passed the literal keyword to the SVG value parsers and were mis-parsed. See `SvgCssDomNodeTests.MatchedDeclarations_PaintProperties_ResolveCssWideKeywords` (theory over each property/keyword) and `SvgIntegrationTests` (`fill: revert`→inherited, `fill: inherit`→parent, `fill: initial`→black-not-inherited, end-to-end).
