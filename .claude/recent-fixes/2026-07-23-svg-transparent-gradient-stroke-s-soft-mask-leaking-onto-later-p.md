# SVG transparent gradient stroke's soft mask leaking onto later paint

_Landed 2026-07-23._

**SVG transparent gradient stroke's soft mask leaking onto later paint** (issue #135): a gradient stroke (`stroke="url(#grad)"`) whose gradient has *varying alpha* is realized as a PDF shading pattern plus a `/Luminosity` soft-mask ExtGState (`PdfGraphicsState.RealizeBrush` emits `{gsName} gs`). `GraphicsAdapter.DrawPath(RPen, RGraphicsPath)` — the only adapter entry SVG strokes route through (`SvgRenderer.PaintShape` → `g.DrawPath(pen, path)`) — drew straight to `_g` with **no `q…Q` bracket**, unlike the already-guarded gradient *fill* paths (`DrawPath(RBrush)`/`DrawRectangle(RBrush)`). So the transparent stroke's soft mask persisted in the page-level graphics state (the PDF `gs` SMask only reverts on a `Q`) and masked out any following paint that emits **no** SMask of its own — most visibly a subsequent **opaque** gradient stroke (an opaque gradient has no alpha ExtGState, so `RealizeBrush` emits no `gs` and the stroke inherits the leaked luminosity mask → it renders blank). This is the "sticky" symptom in the report: once one transparent gradient stroke painted, later gradient strokes on the page vanished; whether the SVG viewport clip happened to bracket the leak is exactly what the wrapper styling (padding, `border-radius`+border) perturbed. Fix (one method, `GraphicsAdapter.DrawPath(RPen, RGraphicsPath)`): when `((PenAdapter)pen).Pen.Brush is XBaseGradientBrush`, wrap the draw in `var state = _g.Save(); … _g.Restore(state);` — mirroring the existing fill guard — so the SMask is torn down by a matching `Q` before the next stroke. Audited the sibling adapter draws: `DrawRectangle(RPen)` has no caller at all, and `DrawLine(RPen)`/`DrawPolygon(RBrush)` are only ever called with solid paint (borders, text-decoration); SVG routes every stroke and fill through `DrawPath`, so `DrawPath(RPen)` is the only gradient-reachable stroke entry and no other guard is needed (matching how the reachable fill guards live only on `DrawPath(RBrush)`/`DrawRectangle(RBrush)`). Verified in both PDFium and MuPDF (a transparent gradient stroke beside an opaque one; the opaque frame stays fully visible) and by a content-stream structural regression test (`SvgIntegrationTests.InlineSvg_TransparentGradientStroke_DoesNotMaskFollowingOpaqueGradientStroke`: the region between the two stroke patterns must contain both the first stroke's `S` and a `Q` restoring its masked state — the test fails on the unfixed code). New SVG-showcase row exercises the transparent-beside-opaque case plus gradient strokes inside padded / rounded-bordered wrappers.
