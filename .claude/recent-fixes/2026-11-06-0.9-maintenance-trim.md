# 0.9.x maintenance trim: net11.0 and unsupported components removed

On `maintenance/0.9` (cut from the 0.9.26 release), the repository was trimmed to what
[docs/support.md](../../docs/support.md) says 0.9.x maintenance supports.

- **net11.0 is gone.** `src/Directory.Build.props` is a plain `net8.0;net10.0` list (the SDK-sniffing block
  that promoted to net11.0 is deleted); `global.json` rolls forward by feature band only and no longer allows a
  prerelease SDK; CI no longer installs the .NET 11 RC SDK or runs net11.0 test legs.
- **Components removed:** `PeachDrawing.Win2D`, `.Skia`, `.CoreGraphics`, `.Svg`, `.Text.Brotli`;
  `PeachBrackets.WinUI`, `.Android`, `.Apple`; every example app (`src/examples`, including the Blazor WASM
  demo and `ScreenShowcases`); their test projects, workflows (`android`, `apple`, `coregraphics`, `winui`),
  smoke scripts, publish jobs, API-reference entries, docs pages and nav entries.
- The TestHarness lost its `--svg`/`--svg-text` mode (it rendered through `PeachDrawing.Svg`) and the manifest's
  `svg` field; the site's showcase cards no longer show *View SVG*.
- Kept: the `BrotliDecompression`/`BrotliCompression` seams in `PeachDrawing.Text` (part of the supported engine);
  only the ready-made managed codec package is gone.

Fixes to the removed components belong on `main` (0.10.x), not here.
