# html-canvas WPT: the first honest baseline, and what the runner was hiding

**Idea.** The `html-canvas` testharness module reported 27 of 2,447 files passing because 2,245 files were *skipped*, not because they failed. Two runner rules caused it, and a third bug was behind a crash once they ran.

**Traps found by running it.**
- `TestharnessEvaluator.UnportedHandler` matched any `*.py` word in the page. Every generated canvas test carries `<!-- DO NOT EDIT! ... generated by /html/canvas/tools/gentest.py -->`, so 2,169 checked-in tests were skipped as "needs a ported handler". A comment names the generator; it is not a request for it. Comments are now stripped before matching. No `gentest.py` port is needed: WPT ships the generated `.html`.
- `.sub.` files were skipped outright although `Server/Substitution.cs` implements the variables. `.https.` files now load from `https://web-platform.test:8443` (`WptServer.OriginFor`, `PageOrigin`), so `{{location[scheme]}}` and the `Origin` header a page's requests carry match what WPT serves. All 76 run now; they fail for real reasons (html-in-canvas, `postMessage`).
- Once the generated tests ran, `ctx.drawImage(canvas)` of a canvas onto itself overflowed the stack (`CanvasBitmap.DrawCanvas` held a live reference and replayed it inside itself). It now snapshots the source's operations when called, as the spec says.
- `summary.md` gained a per-directory table (four path segments deep) so each phase shows its delta.

**Baseline (WPT `33926aca`, `--testharness --module html-canvas`).** 2,447 files: 1,494 pass, 953 fail, 0 skipped; subtests 2,585 of 5,012 pass. Floor raised from 995 to 2,575 (`wpt-floors-dom.json`).

**Not done.** Everything in the plan for 100% (color, host surface, geometry/shadows, layers/filters, text, pixels/offscreen, html-in-canvas). See [the gap file](../accepted-gaps/canvas-2d-gaps-and-peachdrawing-audit.md).
