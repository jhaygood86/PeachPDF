# `capitalize` by UAX #29 word, and a face chosen from the transformed text

**`capitalize`** (`TextTransformer.ApplyCapitalizeFull`) puts the first letter of each UAX #29 word (`Segmenter.FindWordBoundaries`, which css-text-3 section 2.1.1 suggests) in title case, with the full title mappings. So `editor-in-chief` is three words (`Editor-In-Chief`), `1st` is left alone (its first character is a digit), a letter number such as `ⅰ` becomes `Ⅰ`, and in Dutch an `ij` that starts a word is capitalized as a unit. Inline box boundaries and out-of-flow boxes must not start a word (same section): `CssBox.PrecedingWordText` walks back over the in-flow text before the box (skipping out-of-flow and `display: none` boxes) and hands the end of the word it finds, if any, to the transform as context. Two existing tests asserted the old whitespace notion of a word (`editor-in-chief`, `123abc` in SVG) and were changed to the new one.

**The 16-test win, found by diffing the PNGs rather than guessing:** `CssBox.ResolveWordFont` read the character that picks a per-codepoint face from `OriginalText`, the *source*. A transform that changes the character (`ǆ` -> `ǅ`, a full-width letter) then measured the word with the face of the source letter, so a face that has one but not the other drew a different advance. It reads `PreMirrorText` (the transformed text, logical order, never mirrored) now. css-text +16 from that one line, across `upperlower`, `capitalize` and `fullwidth`.

**Also:** SVG text uses the full mappings (`SvgTreeBuilder.ApplyTextTransform`; a letter stands in for the word that ended the previous fragment). `min-content` leaves out the space separator that hangs at the end of each word before a break (`fullwidth-008`). A nested `white-space: nowrap` run (a nowrap span whose text is split around an inner span) is measured and moved as a whole from its outermost nowrap ancestor (`NoWrapRunRoot`, `WidthOfWordsWithin`), where each piece used to be judged on its own and wrapped away from the first.

**Measured:** css-text 861 -> 890 on a Mac over this and the commit before it (floors 843 -> 864 and css2-flow 1820 -> 1821: the delta, not the Mac figure, since CI's fonts differ). The nowrap change moved no WPT test; `text-transform-full-size-kana-005` still differs from its reference by where a pair wraps at the end of a line.

**Not done:** `text-transform` with several values (`uppercase full-width`, css-text-4: `text-transform-multiple-001`) needs the property to hold a set; the Greek uppercase tailoring (dropping the tonos and dialytika, `text-transform-tailoring-002..005`, marked exploratory); `math-auto`; `text-transform-shaping-001..003` (shaping across inline boxes, not a transform issue); `text-transform-capitalize-034`, which differs by layout around an empty absolute box, not by the text. `text-transform-upperlower-016` is not fixable: see [the accepted gap](../accepted-gaps/text-transform-upperlower-016-expects-the-simple-greek-mapping.md).
