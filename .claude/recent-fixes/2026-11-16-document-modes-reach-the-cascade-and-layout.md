# Document modes reach the style sheet, the cascade and layout

The parser already told quirks mode from the DOCTYPE and threw the answer away. It now keeps it (`DocumentMode`: no-quirks, limited-quirks, quirks; `HtmlParser.ParseDocument(..., out mode)`) in `HtmlContainerInt.DocumentMode`, set in `DomParser.GenerateCssTree` before anything is cascaded, with `HtmlDocumentOptions.DocumentMode` as an override.

- **The quirks rules are a block of the one user-agent sheet under `@media (-peachpdf-quirks-mode)`, not a second sheet.** The base `CssData` is chosen before the document is parsed and may already be merged with a host's sheet, a second sheet would need a clone and a fresh rule index per document and a guard for `--no-default-style`, and the media query is already evaluated per rule per box (`MediaQueryContext` carries the flag, and the restyle paths that rebuild one read it from the container). The feature needed a registered `MediaFeature` with a converter that accepts an empty value: `Converters.BinaryConverter` rejected the boolean form `(-peachpdf-quirks-mode)` and the whole block was silently dropped.
- **Trap: style sharing.** `CanShareStyleAmongSiblings` looks at the candidate rules whatever their media, and the margin rules of 15.3.9 are structural (unstable) and have a subject with no tag, so they sit in the universal bucket: every element of every standards-mode document would have lost sibling style sharing. `IndexedRule.QuirksOnly` (from `MediaQueryMatcher.RequiresQuirksMode`) lets a document that is not in quirks mode skip them. A test pins it (`OnlyTheQuirksBlockOfTheUserAgentSheetIsQuirksOnlyForStyleSharing`).
- **15.3.9 is written with three internal pseudo-classes, not `:first-child` and `:empty`**: the standard's "substantial" counts text, and `:first-child` does not, so `text<p>` would have lost the paragraph's margin. `-peachpdf-no-substantial-previous`, `-peachpdf-no-substantial-following` and `-peachpdf-blank` are `QuirkSiblings`. They stop at the first substantial sibling. An empty `<span>` is an element, so it is substantial: a `p` holding only one is not blank.
- **The margins are physical (`margin-top`), not logical**, for the reason at the `hr` rule: a logical declaration in the user-agent origin beats an author's physical one.
- **The lexer cuts `00ff00` into the dimension `00ff` and the number `00`** (a unit stops at a digit), so the hashless color is read from a run of adjacent identifier, number and dimension tokens as the text they make, and only after the declaration was invalid as written. The unitless length is the same retry (`QuirkyValues`, in `StylesheetComposer.CreateDeclarationWith`), and a host's sheet is never read with it.
- **`1e3456` is a number token with an exponent, not an integer**, and is not a hashless color.
- **A table's `font-size: initial` is `medium`, which is 11pt on paper in this engine (a browser's 16px)**, so a quirks-mode table is 14.67px, not 16px. `DefaultFontResolver` owns that, and the tests say 11pt.
- **Layout, by the central functions:** no strut (`LineBoxContributionOf`, `TryGrowLineForBaselessAtomic` and the two other places a strut was added by hand), `IsQuirkyEmptyInline` for the inline ancestors and `PlaceEmptyInline`; `PercentageHeightBase` for the percentage-height quirk (the three height sites; widths and the aspect-ratio read keep `PercentageBase`); `ApplyQuirksViewportFill` at the end of `ApplyHeight`; `IsQuirksTableCell` in `ActualBoxSizeIncludedHeight` only, so widths stay content-box; `DecorationContent.Collect` for the table (it is only asked of descendants, so a table that decorates itself is untouched, and the check has to be at the top of `Collect` because `Of` calls it for the direct children).
- **Not done:** see the accepted gaps for the collapsing table, the origin of a style sheet, vertical writing modes and the alt-text quirk.
- **Evidence:** engine suite, `PeachBrackets.Tests`, `PeachPDF.Tests`, `PeachPDF.Cli.Tests`, `PeachDrawing.Skia.Tests`, `PeachBrackets.Avalonia.Tests`, `PeachBrackets.WptRunner.Tests` and the source generator tests pass; two existing tests changed (a class-case test now says which mode it is about, and a `<p>` first in a doctype-less body gained a DOCTYPE). The WPT floors have not been run (they need a WPT checkout).
