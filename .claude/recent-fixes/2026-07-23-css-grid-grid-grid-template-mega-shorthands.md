# CSS Grid `grid` / `grid-template` mega-shorthands

_Landed 2026-07-23._

**CSS Grid `grid` / `grid-template` mega-shorthands** (issue #264, closing the last of the #232 shorthand deferrals — [CSS Grid §7.4](https://www.w3.org/TR/css-grid-2/#explicit-grid-shorthand)/[§7.8](https://www.w3.org/TR/css-grid-2/#grid-shorthand)): the two shorthands now parse and expand. Pure Layer-A (CSS-OM) work — the longhands (`grid-template-rows`/`-columns`/`-areas`, `grid-auto-flow`/`-rows`/`-columns`) and layout engine already exist and re-parse their token slices, so **no engine change**. A shared `GridTemplateShorthand` (`src/PeachPDF/CSS/ValueConverters/`, sibling to `GridPlacementShorthand`) holds the partition/validation logic: `TryParseTemplate` handles `none`, the `<rows> / <columns>` form, and the **areas form** `[<line-names>? <string> <track-size>? <line-names>?]+ [/ <columns>]?` — a row scanner walks the pre-`/` run, feeds the `<string>`s to `GridTemplateAreasGrammar` and **synthesizes the `grid-template-rows` track list** (line-name groups + per-row track sizes, inserting `auto` for a size-less row) validated via `GridTrackListGrammar`. `TryParseAutoFlowSide` parses the `grid` auto-flow forms (`[auto-flow && dense?] <track-size>*`). Two thin converters (`GridTemplateShorthandValueConverter`/`GridShorthandValueConverter`) emit a `MappedShorthandValue` over the covered longhands (an omitted slice resets that longhand to its initial value via `ShorthandProperty.Export` — exactly what `grid`'s "reset the auto-* longhands" and the untouched template axes need), or `null` to drop an invalid value. The top-level `/`-split needs no depth counter (functions are single `FunctionToken`s, `[name]` groups hold only idents); synthesized multi-token slices carry explicit `Token.Whitespace` because `ToText()` concatenates without separators. Both are registered via `AddLogicalShorthand` (the `_logicalShorthands` serialization-**exclusion** set — its comment broadened to "shorthands never reconstructed from longhands", now also home to the grid mega-shorthands) so `ToCss()` never re-collapses the longhands into a `grid`/`grid-template`. `var()` rides the existing whole-shorthand cascade-deferral path for free. Verified by `GridTemplateShorthandTests` (accept/reject/serialization/var-deferral) and a `GridLayoutIntegrationTests` areas-form case that lays out through the expansion (proving the synthesized rows round-trip into Layer B). **Accepted simplification:** an omitted longhand serializes as the CSS-wide `initial` keyword (the existing shorthand-reset mechanism), not the resolved initial value — functionally equivalent at computed-value time.
