# Per-page left/right `@page` margins now reflow content to the page's own width

_Landed 2026-07-21._

**Per-page left/right `@page` margins now reflow content to the page's own width** (issue #143): previously only per-page *top/bottom* overrides were layout-affecting (variable band *height*, #142); left/right overrides merely shifted + clipped at paint time, so text never re-wrapped to a page's own measure. Now main-column block content re-wraps to each page's own content-box *width* per [CSS Paged Media 3](https://www.w3.org/TR/css-page-3/#page-model) ("the edges of the page area act as a containing block for the layout that occurs between page breaks"). **The one idea that makes this tractable:** layout keeps content anchored at the *base* left origin and varies only the *right edge* (width) — so the painter's existing per-page `deltaX = mL - MarginLeft` translate (`PdfGenerator.AddPdfPages`) still moves content to the page's physical left edge and, with content already at the page's own width, the right edge lands correctly — **paint is unchanged**. New `PageGeometryTable.HasHorizontalMarginOverrides` gate + `HtmlContainerInt.UseVariablePageWidth`/`PageContentRightOf(y)` (the horizontal analogue of `PageBandHeightOf`, keyed off the geometry table's already-stored `MarginLeftPt`/`MarginRightPt`). The single width seam is in `CssLayoutEngine.GetBoxWidth`: when the box's containing block is the main column (`IsMainColumnContainer` — root/`<html>`/`<body>`), the auto-width available-right term uses `PageContentRightOf(box.Location.Y)` instead of `ContainingBlock.ClientRight`; this flows automatically into `CreateLineBoxes`' `limitRight` and `ApplyHorizontalAlignment`. Because a box's width is resolved *before* its `Location` is assigned in a pass, `HtmlContainerInt.PerformLayout` runs a bounded reflow loop (keyed off each box's previous-pass `Location.Y`, capped at 3, exits on a stable box→page-index `PageAssignmentSignature`); for `:first`/`:left`/`:right` (content-independent bands) it converges in one re-pass. Gated so uniform-margin documents keep the byte-for-byte historical single-width path. A box spanning a page boundary keeps its start-page measure (CSS Fragmentation 3: fragments share one inline size — spec-correct, not a gap). Scoped to auto-width main-column blocks; flex/table/multicol, percentage/fixed-`width` blocks, nested (non-main-column) content, ICB-relative resolution against the first page's area, and named-page L/R width iteration are deferred (see accepted gaps). See `PerPageHorizontalReflowLayoutIntegrationTests`.
