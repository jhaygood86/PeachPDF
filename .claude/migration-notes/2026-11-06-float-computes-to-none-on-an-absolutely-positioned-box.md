# An absolutely positioned box with `float` no longer moves the text beside it

A box with `position: absolute` or `fixed` that also has `float: left`/`right` (a leftover `float` in a stylesheet, a utility class applied to a positioned element) used to act as a float for the text beside it: the lines were narrowed (the text started to the right of the box's width, over the space the box was not taking) or, for a right float with no insets, pushed below the box, and a page-float value (`float: top`, `bottom`, `top-bottom`, `snap`) reserved the box's height at the top of the page, moving the content below it down. The computed `float` is now `none` there (CSS 2.1 §9.7), so the text starts where it would without the box. The box itself is placed as before, by its insets. The same holds for a declaratively built tree (`SetStyle`, a stylesheet rule), where an absolutely positioned box is now also blockified as in HTML.
