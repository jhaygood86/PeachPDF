# Tiled background layers need nearest-neighbour scaling to interlock

Two intentionally-offset, tiled `background-image` layers meant to interlock into a solid color (see [Acid2's checkerboard-interlock band](acid2-checkerboard-interlock-band.md)) require `image-rendering` equivalent to `pixelated`/nearest-neighbor to actually cancel out — `RImage.Interpolate` is forced off for the duration of any `background-repeat` (fixed in this round; see `BackgroundImageDrawHandler.DrawBackgroundImage`) but a plain non-repeating `<img>`/`background-image: no-repeat` still defaults to smoothed (`Interpolate = true`), matching most real UAs' default `image-rendering: auto` behavior — PeachPDF has no CSS `image-rendering` property support to let authors request crisp scaling for a single (non-tiled) image.
