# SVG text with a `<tspan>`/`<g>`-level `objectBoundingBox` is measured per `<text>`

Two small approximations remain after the `<textPath>` work (issue #289, closed): the bounding box that `objectBoundingBox` units resolve against is measured for a `<text>` element itself (the union of its glyph cells, `MeasureTextBounds(forPaintExtent: false)`), so a `clip-path`/`mask` on a `<g>` or `<use>` whose only content is text still resolves against no box (`SvgGeometryBounds.GetBoundingBox` returns null for text); and a bitmap-only font's `stroke` is a morphological band (the glyph coverage grown and shrunk by half the stroke width, with a square window) because a bitmap has no vector edge to stroke. Not tracked as spec deviations beyond that.
