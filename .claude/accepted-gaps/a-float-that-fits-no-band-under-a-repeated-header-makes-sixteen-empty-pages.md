# A float that fits no band under a repeated `thead`, in a table cell, makes 16 empty pages

`<table><thead>...</thead><tbody><tr><td><table><tbody><tr><td><div style="float:right;height:90pt">` on a 160pt page with 20pt margins stalls: no pass places the float, because the repeated header leaves it a hair too little room on every page. The driver's stall guard (16 passes that resume at the same place) lays the remainder out in one piece, so the document finishes, but each of the 16 stalled passes was already emitted as a page that holds only the header: 18 pages where Chrome has 2 (it places the float at the top of the second page and lets it overflow, css-break-3 section 4.4; tracking issue #2297). A float of 80pt or less fits, 85pt goes to a second page, about 88pt and more stalls; without the `thead` it is one page. #2293 was the same document with `rowspan` cells, where the guard never fired and the render did not finish.
