# Segmentation: the tables are generated, and the algorithms are checked line by line against Unicode's conformance files

`src/PeachDrawing.Text/Internal/Text/Segmentation/SegmentationData.g.cs` is generated by
`assets/unicode/generate_segmentation_tables.py` from the vendored UCD files (Unicode 18.0.0). Never edit it by hand, and refresh
it only together with the `.txt` files and the four conformance files beside them (`LineBreakTest.txt`,
`GraphemeBreakTest.txt`, `WordBreakTest.txt`, `SentenceBreakTest.txt`).

- **`SegmentationConformanceTests` runs every line of those files** through `LineBreaker` (with `Strictness = Strict`, the
  algorithm's own default, because `CJ` is `NS` there) and `Segmenter`, and is the reason to trust the rules. A change to a rule
  that makes one line fail is wrong; do not "fix" it by editing the test.
- **The tables are source, not a Brotli resource**, so they work in WebAssembly, where there is no Brotli decoder. A lookup is a
  binary search over a sorted array of range starts with a parallel array of values.
- **Everything the line breaking rules need beyond `Line_Break` comes from the comment of `LineBreak.txt`** (the General_Category
  of each listed code point: Pi, Pf, Mn/Mc for `SA`, Cn for LB30b), East Asian Width and Extended_Pictographic. A code point the
  file does not list is treated as unassigned. If a future `LineBreak.txt` drops the comments, the generator has to read
  `DerivedGeneralCategory.txt` instead.
- **The line breaker works on units, not characters.** LB9 folds each combining mark or joiner into the character before it, so
  every later rule reads a unit's class, and a break inside a unit is prohibited. LB8a still asks whether the *actual* last
  character of the unit is a ZWJ.
- **The word and sentence rules skip Extend, Format and (for words) ZWJ** by working on an "effective" sequence with those
  characters absorbed into the one before them, except after a newline or a paragraph separator, where they stand alone. The rules
  that read the original neighbour (CR LF, newlines, ZWJ before a pictograph, adjacent spaces) run before that.
