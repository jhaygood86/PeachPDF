# Inside a container, which fragmentainer a box is in is an *index* question, not a geometric one

_CSS Fragmentation Level 3. Tracker: [#320](https://github.com/jhaygood86/PeachPDF/issues/320)._

Every column shares one block-axis band, so a member of an earlier column has a document Y indistinguishable from this one's, and the coordinate-based guards the page sites use say nothing. The index the fill began at is the only thing that does — and it is also the termination argument, since a box moved to the next fragmentainer becomes the child that fill starts at.
